
## Release Process

Managed by the maintainer. See `CHANGELOG.md` for version history.

### Tag Convention

Tags use **no `v` prefix** — e.g. `0.6.0`, not `v0.6.0`. This convention
applies since version 0.3.0. Earlier tags (`v0.1.0`–`v0.2.3`) used the
`v` prefix and are retained for historical reference.
