# Google Sans Flex

`GoogleSansFlex.ttf` is the unmodified variable font
`GoogleSansFlex[ROND,opsz,slnt,wdth,wght].ttf` from
https://github.com/google/fonts/tree/main/ofl/googlesansflex
(git blob `1d8d8ae5a7c6d0e48312d2a0a478bad92caee73a`,
SHA-256 `a9ac770798857d5e8ac593ced42b22e40a7c08cec98319f92b0eccc2783a77ba`).
Only the file name was shortened; the font data is byte-identical.
