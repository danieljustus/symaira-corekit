## Overview

Use the shared Symaira family identity without inventing an application UI.

## Colors

Warm black is the canvas; champagne/sand identifies the family; product accent is informational only.

## Typography

Use system/Roboto Flex for prose and a system monospace face for package names, APIs and commands.

## Composition

Prefer architecture maps, contract tables, dependency arrows and release evidence over dashboard cards.

## Components

Documentation fixtures include callouts, status rows, contract tables and copyable commands.

## Accessibility

Maintain readable contrast, visible focus, reduced motion, forced-colors support and reflow at 390 px.

## Release assets

Keep editable SVG beside PNG/PDF exports and record source repository provenance.

## Anti-patterns

No fake GUI, no hosted/billing claims, no secrets, no unverified version or release status.
