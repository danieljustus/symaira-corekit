# Symaira AppKit — OpenDesign handoff

## Purpose

This project is the design handoff for **Public Swift design and app foundation**. Start here instead of guessing which render, source, or prototype is current.

## Open first

- `asset-board.html` — visual index of UI/UX and public assets.
- `No GUI prototype by design` — this project intentionally has no GUI shell.
- `DESIGN.md` then `tokens.css` — normative local design rules.
- `assets/manifest.json` and `assets/provenance.json` — machine-readable handoff.
- `RELEASE_ASSET_GUIDE.md` — where each export belongs.

## Boundary

This is a Brand & Assets project. Do not create a fake app dashboard.

## Apple status

No Apple app icon is required while this remains a non-GUI CLI/MCP product.

## Vollständiges Repository-Programm

- `symaira-appkit-complete-program.html` — 6 End-to-end-Programme mit 35 Schritten und 33 Pflichtzuständen.
- `PROGRAM.md` — kompakte Programmliste.
- `program-manifest.json` — maschinenlesbare Abdeckung.
- `QA_PROGRAM.md` — verifizierte Interaktionen und Releasegrenzen.
