# Usage

## Read order

1. `PRODUCT_CONTEXT.md`
2. `DESIGN.md`
3. `tokens.css`
4. `PROJECT_CATALOG.md`
5. `RELEASE_ASSET_MATRIX.md`
6. `family-assets-board.html`

## Do

Use product-local project assets for publishing and this project for common rules and templates. Verify every release claim against the live repository before publishing.

## Avoid

Do not turn the family system into a product UI or overwrite product-owned assets automatically.
