# Symaira product logo exports

These 1024 × 1024 transparent PNG files are the canonical product-logo
lockups for the Symaira design family.

- Preserve the original aspect ratio and transparent padding.
- Do not recolour individual products.
- Place the artwork over native platform material when a Liquid Glass app
  icon is required; do not rasterise the glass effect into this source.
- Use Roboto Flex for any newly rendered product name.
- `SymDesk` is the intentional naming exception; all other user-facing app
  names follow `Symaira <Product>`.

Standalone repositories vendor their matching file at
`assets/branding/product-logo.png`. The public website mirrors this directory
at `/brand/product-logos/`.
